# A REA viralizou no GitHub
## A REA (Reverse Engineer Anything) é um projeto open source que permite a um agente de IA analisar programas compilados sem ter o código-fonte.
Ela funciona como ponte entre o agente (via MCP) e decompiladores como Ghidra, Hopper e IDA Pro.

Devolve pseudocódigo e assembly com evidências, não os arquivos originais dos programadores.

Uma cópia falsa do repositório espalhou um trojan, então baixe só do repositório oficial, do site ou do npm.

Não é uma sandbox, por isso vale usar um perfil separado do agente.
